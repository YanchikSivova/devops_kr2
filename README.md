# KR2 template — вариант 2

Сервис-счётчик на Flask и Redis. Для варианта 2 приложение слушает порт
`8002`; публикация приложения на сервере в рамках этой правки не выполняется.

## Переменные окружения

Скопируйте `.env.example` в `.env` и задайте собственный пароль Redis.
Файл `.env` не добавляйте в Git. В рабочем Compose-конфиге для варианта 2
используются имя хоста Redis `redis` и порт приложения `8002`.

## Локальный запуск

Установите зависимости из `requirements.txt`, задайте `REDIS_HOST` и
`REDIS_PASSWORD`, затем запустите:

```powershell
gunicorn --bind 0.0.0.0:8002 app:app
```
